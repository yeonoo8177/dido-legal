dido 隱私權政策

生效日期:2026 年 7 月 26 日

dido(以下稱「本服務」)重視使用者之個人資料,並依下列方式蒐集與利用。 拍照、去背與製作卡片在裝置上處理。允許位置權限後,建立新卡片時會依 目前位置取得區域名稱與附近甜點店候選,並將座標及所選店家資訊用於個人 甜點地圖。登入後,這些位置資訊也會與卡片、圖片及寵物紀錄一起自動同步 到只有本人帳號可存取的非公開備份。位置資訊不會傳送至假名化統計或商業 分析。照片的 EXIF 等內嵌中繼資料會移除,但像素中可見的招牌、地址、 地標及自由輸入的地點線索仍可能進入非公開備份。

1. 儲存於裝置與非公開備份之資料

未登入時,拍攝或選取之原始照片、去背影像、包含座標、區域名稱、 店家候選、所選店名與地點 ID 的卡片、筆記與寵物狀態儲存於裝置。 登入後,這些卡片位置資訊、卡片本文、重新編碼的場景圖／去背圖／ 背面圖／朋友去背圖,以及寵物名稱、成長、餵食與獎勵帳本會自動備份 及同步至本人帳號之非公開儲存空間,亦可於設定中手動執行。支援影像會 將方向套用至像素,移除 EXIF、GPS 等內嵌中繼資料後重新編碼為 PNG。 但不會抹除像素中可見的招牌、地址或地標,這些內容與品項名稱、備註中 直接填寫的店名、地址等地點線索仍可能進入非公開備份。無法安全解碼的 原始容器不會上傳。App 只會清理拍照後由 App 擁有的暫存快取, 不會刪除從相簿選取的原始圖片。未登入時不會將照片、卡片或寵物狀態上傳。

用於重複提醒的 sourceHash 是所選原始位元組的 SHA-256, 只會隨卡片保存於裝置,不會寫入帳號備份。遠端圖片物件名稱使用無中繼 資料 PNG 位元組的 SHA-256 內容雜湊。此值與 sourceHash 不同,是確定性的內容位址,不保證為隨機或 匿名識別碼。

目前發行版不會再隔離或刪除現有卡片的一般位置欄位;但先前停用版本 已移入卡片內部本機專用隔離區的值不會自動還原或重新使用,並會隨該 卡片或帳號刪除。舊版依地點保存的造訪鍵放在另一個本機 造訪帳本隔離區;刪除單張卡片不會清除該帳本,只有退出會員或完全清除 本機資料時才清除。兩者未經另行法律審查及使用者明確選擇都不會再次使用。

2. 傳輸至外部之資料

  • AI 命名建議與變體圖片:AI 命名建議為選用功能。只有在使用者確認 已年滿 14 歲且於設定中開啟時,才會將去背照片的縮小版透過本服務的 Supabase 中繼伺服器跨境傳送至 Google Gemini 3.5 Flash-Lite;API 金鑰只保存在伺服器。依付費契約,Google 不會使用這些資料訓練模型。 拒絕或關閉時,不會開始縮小、編碼或傳送。去背僅於裝置上處理,名稱 建議僅在使用者確認後套用,也不會擅自覆寫手動輸入的名稱;即使失敗, 也會繼續建立卡片。命名建議的發行許可邊界只由編譯時原始碼決定, 設定或伺服器回應無法變更。AI 變體圖在原始碼層關閉,不會產生任何 變體圖片。
  • 位置、地點與地圖:目前發行版只宣告及要求使用 App 期間的位置權限, 不使用背景位置或永遠允許的位置權限。透過相機建立新卡片時,會以低 精確度取得目前位置,最長 4 秒;開啟個人地圖時,還可能為地圖中心與附近 卡片再次以低精確度取得目前位置,最長 5 秒。作業系統的反向地理編碼 用於取得區域名稱與國家代碼。在韓國或國家不明時,為搜尋半徑 250 公尺內的咖啡廳、烘焙店與甜點店候選,座標會直接傳送至 Kakao Local API,或經由本服務的代理傳送;在韓國以外的 iOS 上使用 Apple MapKit 的附近地點搜尋。卡片會保存座標、區域名稱、候選名稱與 ID 清單, 以及使用者選擇的店名和地點 ID。MapKit 原始 ID 只保存其 SHA-256 摘要;Kakao 文件 ID 為驗證所選店家而按原值保存。登入後,這些卡片 位置資訊會進入本人帳號的非公開備份;個人地圖只顯示本人座標不為 0 的卡片。拒絕權限或定位、反向地理編碼、搜尋失敗時,仍會繼續建立不含 位置的卡片並正常使用 App。使用者手動填寫的店名或地址會作為卡片本文 保存在裝置與非公開備份中,不作分析使用。照片的 EXIF、GPS 等內嵌 中繼資料會移除,但像素中可見的招牌、地址或地標不會抹除。先前停用 版本已移入卡片內部隔離區的值不會自動還原或重新使用,並會隨該卡片或 帳號刪除。此功能邊界只在編譯時由原始碼決定,不能透過環境變數、儲存 設定、API 金鑰、伺服器回應或遠端設定變更;變更需要新程式碼與新的 簽署版本。
  • 提供假名化使用紀錄(選擇性):境外處理設定已確定(主要儲存與處理位於 大韓民國首爾區域,詳見第 3 節),因此自本發行版起,僅對已同意的 使用者建立並傳送伺服器假名事件。未同意者不會建立事件,也不會 累積待傳佇列。 會傳送:卡片參照值、生命週期版本、輸入來源、體驗／ 建立時間、日期信賴度、是否為過往紀錄,以及品項名稱、品項分類、 配料、代表色;評分時另含口味／外觀／氛圍評分與選項式 關鍵字;此外還有角色解鎖、品項素材缺漏與通知相關紀錄。每筆 事件會附上安裝單位的假名識別碼(anon_id)、刪除權杖雜湊與同意 revision。 不會傳送:卡片的座標與區域名稱、店名、店家 ID、店家 確認狀態(第三方資料再利用權利尚未確認)、自由輸入的備註與一句話評論 原文、照片及照片路徑。座標會在最終傳輸邊界移除;登入後進入本人帳號的 非公開位置備份與本項蒐集彼此獨立。目的為品項趨勢分析與產品改善, 不進行地區層級分析。本次蒐集內容,以及舊版依法蒐集的伺服器原始事件或驗證中繼資料, 均適用下述保存、撤回與刪除程序。同意前建立的卡片不會追溯傳送。 若要擴大蒐集項目或目的,會在新說明中重新列明項目、目的、保存期間、 境外處理及位置法規分類,並另行取得新的同意 revision。不會以既有選擇、 過去卡片、本機隔離值或舊版備份為依據追溯蒐集。
  • 【選擇性】人口統計(年齡層、性別):僅在向年滿 14 歲的使用者取得 與假名紀錄提供分開的同意時,才會在卡片建立事件中 一併傳送年齡層與性別區間。生日或實際年齡的原始值 不保存也不傳送。此項同意可單獨撤回,撤回後的事件不再帶入區間。
  • 防止網路濫用:對於伺服器蒐集、刪除及購買驗證等受配額限制的 Edge 要求,dido 的 Edge 程式碼會在處理要求期間,於記憶體中暫時 讀取並正規化閘道所確認的來源 IP 位址,再以伺服器秘密金鑰 HMAC 產生各路徑的呼叫者儲存區。dido 的配額資料庫不會儲存原始 IP 位址,只會儲存 64 位 HMAC 儲存區、要求路徑、時間區間及次數; 配額資料列不會記錄原始 IP 位址、要求本文、驗證權杖、照片、座標 或購買收據。時間區間開始超過 2 日的儲存區會每日刪除。此儲存區 僅用於濫用及成本限制,不會用於使用分析、剖析、個人化或商業彙整。 開啟 AI 命名建議時,中繼函式會先驗證要求並套用配額,再呼叫 Google; AI 變體圖片要求則在原始碼層遭拒絕。
  • 登入、備份與購買驗證:Kakao 登入時可能提供電子郵件、暱稱與個人頭像; Apple 登入時可能提供電子郵件與姓名(fullName)。Supabase 帳號 UID 與驗證中繼資料用於驗證及非公開備份。Apple 姓名目前不會另存至 App 資料庫。於 iOS 刪除已連結 Apple 登入的帳號時,伺服器會接收 為該刪除要求新取得的一次性 authorization code,以及 App 產生的 隨機 nonce。伺服器將 code 向 Apple 交換為權杖,驗證權杖的簽章、 發行者、對象、nonce 雜湊及帳號 subject 後,立即撤銷所交換的權杖。 code、nonce 與交換所得權杖不會儲存於資料庫或日誌,僅在處理該要求 期間使用。系統會先嘗試自動交換、驗證與撤銷;即使失敗或沒有可用的 code/token,dido 帳號、非公開備份及帳號所屬原始事件的刪除仍會繼續。 此時會在刪除完成後提示使用者於 Apple 設定或 account.apple.com 手動解除 Apple 連結。刪除完成證明只保留 not_applicable、revoked 或 manual_required 結果,不會儲存 Apple code、token、 nonce 或 subject。非公開備份包含卡片本文及座標、區域名稱、店家候選、 所選店名、地點 ID,重新編碼的場景圖／去背圖／背面圖／朋友去背圖, 以及寵物名稱、成長、餵食與獎勵帳本。目前不會將位置或新事件用於以 UID 為基礎的分析。購買或回復時,商店收據不附帶帳號資訊, 傳送至 Supabase 購買驗證函式進行匿名驗證;iOS 收據會轉交 Apple 驗證。

3. 委託處理與第三人

為提供服務,本服務將處理作業委託予下列業者:Kakao(登入,以及韓國或 國家不明地區的周邊店家候選搜尋)、Supabase, Inc.(美國業者;帳號、 本人專用的非公開備份、Kakao 搜尋代理、AI 命名建議中繼、購買收據驗證 及刪除確實仍存在的歷史原始事件)、Google(透過 Gemini 3.5 Flash-Lite 付費版提供選用 AI 命名建議)、Apple(登入、韓國以外 iOS 的 MapKit 地點搜尋、 iOS 收據驗證,以及刪除 Apple 連結帳號時的一次性 code 交換與權杖 撤銷)、OpenStreetMap Foundation(英國;韓國以外市場的甜點地圖背景圖磚)。 地圖圖磚由裝置直接向圖磚伺服器請求,因此會傳送 IP 位址與可見區域的座標, 這是為了繪製使用者開啟的地圖所進行的處理。韓國市場使用 Kakao Map, 沒有此路徑。Kakao 候選搜尋會直接或經由本服務代理傳送半徑 250 公尺搜尋 所需的目前座標;代理不會附加登入帳號工作階段。作業系統的位置及反向 地理編碼功能用於取得區域名稱與國家代碼。位置結果只保存在本人卡片與 非公開備份中,不傳送至假名事件或商業分析,也不會呼叫事件用的 Google Play Integrity 或 Apple App Attest。AI 命名建議僅在確認已年滿 14 歲 並開啟後,才會透過 API 金鑰只保存在伺服器的 Supabase 中繼函式,向 Google 傳送去背照片的縮小版。依付費契約,Google 不會使用這些資料訓練 模型;關閉後不會傳送照片。AI 變體圖片不會產生。假名事件的主要儲存與處理區域為大韓民國(首爾, ap-northeast-2)。接收方為 Supabase, Inc.(美國),移轉項目為 上述第 2 節的假名事件項目,移轉目的為資料庫代管與技術支援過程中 的存取,移轉方式為透過管理控制台與支援管道的存取,移轉時間為 需要支援時,保存期間如下述第 4 節。除此範圍的支援存取外,不進行其他 境外移轉。Supabase, Inc. 為美國業者,營運與支援過程中可能於境外處理資料。各業者僅於委託範圍內 處理資訊。

為提供周邊店家候選所需的目前座標,可能會依上述方式傳送至 Kakao Local API 或韓國以外 iOS 的 Apple MapKit。這是為執行使用者要求的 地點搜尋所進行的處理,與本人帳號的非公開備份也彼此獨立。除此以外, 目前外部資料集、接收方契約及向合作方傳送的路徑均為關閉,不會向合作 咖啡店或品牌提供位置、地區趨勢或人口區間,也不會建立新的內部審核信號。 未來如要開始內部分析或第三方提供,須另行取得新的同意 revision、接收方／目的／保存期間契約, 並完成法律、個人資料、安全、品質、商店、實機審查及資料庫核准程序。 不會追溯使用既有選擇、卡片、隔離值或舊版備份。

4. 保存及利用期間

下列期間為目前伺服器實作的最長上限。若處理目的已達成、收到合法的 撤回、刪除或停止處理要求、退出會員,或法令要求更短期間,將優先刪除 或停止處理。

類別保存期間及刪除標準
裝置內資料及帳號非公開備份 裝置內資料保存至使用者自行刪除,帳號備份保存至退出會員。卡片的 座標、區域名稱、店家候選、所選店名與地點 ID 也會隨卡片保存; 登入後會同步到本人帳號的非公開備份。刪除卡片時,該卡片的位置資訊 與地圖圖釘也會從裝置刪除,並反映於下一次非公開備份更新。先前停用 版本已隔離在卡片內部的位置值不會自動還原,並會隨該卡片或帳號刪除。 獨立造訪帳本隔離值不會 隨單張卡片刪除,只於退出會員或完全清除本機資料時清除。舊版遠端 備份不會由一般同步讀取、刪除或遷移,但退出會員會刪除該 UID 下 目前與舊格式的全部備份。在導入支援多裝置安全的伺服器世代 CAS 與寬限期 GC 前,卡片刪除或替換後不再由 manifest 引用的內容定址 遠端圖片物件也可能在非公開儲存中保留至退出會員。
既有選擇提供之原始事件、事件接收收據及已完成之完整性要求 已同意使用者的假名原始事件,以及舊版依法蒐集的既有資料, 適用最長 12 個月。依伺服器接收時間、事件時間及 卡片體驗日／建立日界線每日刪除。若 12 個月刪除作業未在 36 小時內成功,將停止蒐集新的原始事件。
完整性驗證暫時狀態 到期且未處理之 challenge／要求於到期後 1 日界線、已處理 challenge 於處理後 7 日界線、已停用 App Attest 金鑰於停用後 30 日界線每日刪除。長期未使用之有效金鑰及已完成要求於最長 12 個月界線刪除。
秘密金鑰 HMAC 配額儲存區 自時間區間開始起最長 2 日。每日刪除,且原始 IP 位址不會 儲存於配額資料庫。
撤回及刪除處理 intent 保存至各 intent 所設定的到期時間,並於到期時每日刪除。 處理中的安裝 UUID 及所有權驗證值雜湊於完成時移除。
防止刪除後重建／重送之紀錄 與原始事件分開,於相關蒐集及刪除機制運作期間保存;機制終止 或法律、營運依據消滅時刪除。如下所述,不含原文、位置、品項或 評分。
未來經另行核准後實際對外提供之審核報告 目前提供件數為 0。僅於未來開始提供時,依提供前核准之各接收者 契約期間保存,最長不超過 365 日。期間結束時記錄接收者的刪除 確認;在尚未確認期間,停止新的對外提供。

舊版依法蒐集的原始事件確實仍存在時,撤回或退出會員的刪除要求會在 驗證所有權後提出,並於網路可用時重試, 待伺服器完成處理後完成刪除。為在原始事件期限屆滿後仍可驗證撤回並 防止延遲或重送,隨機安裝 UUID 及刪除權杖的單向雜湊會與原始事件分開。 登出、撤回同意或退出會員完成時,會移除帳號連結並轉為防止重送紀錄。 為防止退出會員後以快取驗證資料重建非公開備份,並區分處理中與完成 狀態,亦會分開保存隨機帳號 UUID 的單向雜湊、刪除開始時間及驗證 帳號刪除完成時間。為在未收到退出會員處理回應時仍可確認完成狀態, 另行保存使用者裝置建立的隨機刪除要求 UUID、秘密值的單向雜湊、 刪除前清理驗證時間及完成時間。處理中使用的帳號 UUID 雜湊會在刪除 帳號的同一交易中移除,因此完成紀錄不保留帳號識別碼。這些紀錄不含 原始事件、原始帳號 UUID、位置、品項或評分,也不作分析使用。若相應的 歷史彙整確實仍存在,撤回或刪除完成後不再反映該事件;此類彙整不保證為 匿名資料。電子檔案將以無法復原之方式刪除;如有紙本,則以碎紙或 焚燒方式銷毀。

5. 使用者之權利
