요청 방법

  1. 아래 버튼으로 삭제 요청 이메일을 보내세요. 가능하면 dido 계정에 연결된 이메일 주소에서 보내 주세요.
  2. 본문에는 로그인 방식(Apple·카카오·이메일)과 dido 계정에 표시된 이메일 주소만 적어 주세요. 비밀번호, 일회용 인증번호, 로그인 토큰, 영수증 전문, 사진이나 위치는 보내지 마세요.
  3. 운영자는 임의 요청번호를 발급하고, 요청자가 적어 낸 새 연락처만 믿지 않고 계정에 이미 연결된 확인 수단을 이용해 본인 확인을 진행합니다. 확인할 수 있기 전에는 계정이나 데이터가 삭제되지 않습니다.

본인 확인과 상태

계정 존재 여부가 제3자에게 노출되지 않도록 본인 확인 전에는 동일한 접수 안내만 제공합니다. 요청번호는 계정 식별자가 아닌 임의 값이며, 공개 상태 조회 페이지는 제공하지 않습니다. 상태 문의는 요청번호를 포함해 같은 이메일 대화에 회신하세요.

  • 접수됨: 이메일을 받았으며 아직 본인 확인 전입니다.
  • 본인 확인 필요: 계정에 이미 연결된 수단으로 확인을 기다리는 중입니다.
  • 처리 중: 본인 확인이 끝나 삭제를 진행 중입니다. 예상 완료 시점은 이 단계의 안내 메일에 적습니다.
  • 완료: 계정과 삭제 대상 서버 데이터 처리가 끝났습니다.
  • 확인 불가·종료: 소유권을 확인할 수 없거나 요청자가 취소했습니다. 이유와 다시 요청하는 방법을 회신합니다.

삭제되는 데이터와 남을 수 있는 항목

  • Supabase 인증 계정, 계정의 비공개 카드·사진 백업, 계정에 귀속된 설치의 서버 원시 이벤트가 삭제 대상입니다.
  • 원격 요청으로 기기에만 남은 파일을 지울 수는 없습니다. 기기 설정에서 dido의 앱 데이터를 지우거나 앱을 삭제하면 됩니다.
  • App Store·Google Play가 소유한 구매 내역과 상품 권리는 dido 계정 삭제와 별개이며, 구독이 있다면 스토어에서 직접 취소해야 합니다.
  • 지연 재전송과 삭제 후 재생성을 막고 완료를 증명하는 데 필요한 무작위 요청값·단방향 해시·처리 시각 등 최소 기록은 개인정보처리방침에 적힌 범위에서만 분리 보관될 수 있습니다. 원본 사진·위치·메뉴·평점은 이 완료 증명에 포함되지 않습니다.

Request deletion in English

You can request deletion of your dido account and associated server data without reinstalling the app. Email macat.universe@gmail.com with the subject “dido account and data deletion request”. Include only your sign-in method (Apple, Kakao, or email), the email shown on the dido account, a reply address, and your language.

We issue an opaque request ID and verify ownership using a method already associated with the account. A newly supplied contact address alone is not proof. Status is reported as received, verification required, processing, completed, or unable to verify/closed. Reply in the same email thread with the request ID for a private status update.

Never send a password, one-time code, access token, complete receipt, photo, or location. Deletion covers the authentication account, private server backups, and account-linked raw server events. Store purchase history and on-device-only files are controlled separately. Limited deletion-proof records may remain only as described in the Privacy Policy.
